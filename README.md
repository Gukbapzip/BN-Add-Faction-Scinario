# BN Add Faction Scinarios

A faction scenario mod for Cataclysm: Bright Nights.

## Installation

1. Place `BN_Add_Faction_Scinarios` in the game's `mods` folder.
2. Enable `BN Add Faction Scinarios` when creating a world.
3. Start a new world, or explore map tiles that have not generated before.

Generated areas are not retroactively changed in existing saves.

## Faction spawns

| Faction | Map tags | Spawn rate |
| --- | --- | --- |
| Rebels | Military-base building interiors; parking, roads, fields, helipad, and minefields excluded | 90% per interior tile; mech is in the motor pool and seven snipers occupy exterior watchtowers |
| Bikers | `s_gas_*`, `s_gas_1_*`, `s_gas_rural_*` at z0 | 50% per tile, 3-5 NPCs |
| Cyborgs | `afs_augmentation_clinic_*` | 80% per tile; 4 on n1, 4 on n2, 2 on n3 |
| Mutated Scientists | `microlab_*` below z0 | 85% per tile, 4 NPCs |
| Sanitizers | `hospital_*` at z0 | 60% per tile, 2-4 NPCs |
| Flesh Cultists | `mine*` below z0 | 70% per tile, 1-3 NPCs |
| Tunnel Rats | `sub_station_*`, `sewer_sub_station_*`, `underground_sub_station_*` | 25% per tile, 3-12 NPCs |
